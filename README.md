# AdRewardHub 🚀

AdRewardHub is a web-based application designed for rewarding users through interactive ad experiences. This project is hosted live using GitHub Pages.

## 📁 Project Structure

* **index.html**: The main user interface and structure of the app.
* **script.js**: Handles core application logic, user interactions, and functionality.
* **style.css**: Custom styling and responsive design for the application.
* **sw.js**: Service Worker for handling caching, offline capabilities, and progressive web app (PWA) features.

## 🌐 Live Demo
You can view the live project running on GitHub Pages right from the deployment section of this repository.
